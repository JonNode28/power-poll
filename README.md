# Notes on PowerPoll

## Principles

### Rejection

The structure of a subject is determined solely by the author so the community must be able to reject it.

Any vote can be a rejection and any subject can be rejected.

Rejection occurs if a simple majority of votes are rejections. Hard-coding the rule prevents subject types raising excessively high rejection barriers.

### Change

1. Changing the details of a Subject resets it's vote position
